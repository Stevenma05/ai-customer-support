# Northstar Electronics — Return Policy

This is fictional policy content created for the ResolveAI demo.

## Return window

Customers may request a return within 30 calendar days after delivery.

## Eligible products

Products must include their original accessories and packaging.
Products damaged by misuse are not eligible for a return.

## Starting a return

Customers must contact support with their order number to request
return authorization before shipping an item back.

## Return shipping

Northstar Electronics provides a prepaid return label for products
that arrive damaged, defective, or different from what was ordered.

For change-of-mind returns, the customer pays return shipping.

## Refund timing

Refunds are issued to the original payment method within five business
days after the returned product has been received and inspected.

Original shipping charges are not refunded for change-of-mind returns.

## Outside the return window

Products outside the 30-day return window are not eligible for a
standard return. Defective products may qualify under the warranty policy.
